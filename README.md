# Local Community Event Portal

A responsive community event portal built with HTML, CSS, and JavaScript. The page demonstrates core CSS concepts such as selectors, colors, typography, tables, lists, box model, multi-column layouts, media queries, and polished responsive UI design.

## Features

- Sticky navigation bar with custom link states
- Hero banner with background image and gradient overlay
- Responsive event gallery with aligned image cards
- Registration form with saved event preferences using local storage
- Feedback form with phone validation and character count
- Location lookup using the browser Geolocation API
- Promo video section
- Community bulletin using CSS multi-column layout
- Mobile-friendly layout with media queries

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## How to Run

Open `index.html` directly in a browser.

No build tools or package installation are required.

## CSS Concepts Covered

- Universal, element, ID, class, grouping, and pseudo-class selectors
- HEX, RGBA, gradients, and background images
- Google Fonts and text formatting
- Link and list styling
- Table styling with zebra striping
- Box model properties: margin, padding, border, and outline
- `visibility: hidden` vs. `display: none`
- CSS multi-column layout
- Responsive design using media queries, Flexbox, Grid, `%`, `vw`, and `vh`
